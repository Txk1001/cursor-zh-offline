## 发布硬门槛

安装、重复安装、中断恢复、原文完整性、技术内容保护和核心界面必须通过。复杂正文可以明确标注未译并保留原文；任意正文达到人工精校水平不是自动模型的保证。实际环境按 [Windows 验收表](WINDOWS-ACCEPTANCE.md) 留证，包含版本、commit、架构、候选来源、SHA-256、操作、期望、实际、脱敏截图及失败项。

以下不能作为通过依据：文件存在、命令退出成功、配置里允许该版本、模拟 DOM 测试、旧版本截图、只有 CI 配置而没有远端运行。1.0.8 的 [历史修复记录](REPAIR-1.0.8.md) 仅限当时环境。未完成独立环境验收前不标记“可靠公开预览验收通过”。

### 1.1.2 本轮纠错与控件改版（2026-10-25）

- 用户提供的误译按补丁缺陷处理，不据此否定 Cursor 已有中文的质量。自动路径保留已有中文正文、混排段落和标题；明确导入的人工译文仍可覆盖。公共产品名保护表新增 Copilot、Playwright、Context7、MCP Registry、PyPI 等；通用概念仍按规范中文翻译。
- 隔离真实模型曾将 `Run ↵` 译为“运行 QQ”，也复现了中文段落中的产品名误译。本轮将审批按钮与模型隔离，精校为“运行”“始终允许运行”，保留键帽、命令与 RPC 名称。已复现的是同类风险路径，不能认定截图中三个 Q 的具体来源已唯一确定。
- 真实隔离模型的 24 项技术保护、9 项术语和 3 项已有中文/混排保留用例通过；8 项 Python 规则通过。DOM 检查覆盖中文段落、链接/代码、单元格、审批按钮、强调格式失败保留及完整原文恢复。普通多层 span、换行及复杂富文本仍需实机逐项核对。
- 工具条默认紧凑，可拖动、选四角，点击外部或按 Escape 收起；本机偏好可恢复。模拟几何检查覆盖展开、恢复拖动坐标、窗口缩小和控件变高时的边界，不能替代真实窗口、缩放比例与多显示器检查。
- 手动与 Agent 共用相同参数、版本准入、备份和回滚规则，说明见 [配置方法](AGENT-SETUP.zh-CN.md)；独立 Windows 与 Mac 标准语言层的准备见 [测试环境](TEST-ENVIRONMENTS.zh-CN.md)。26ab579 完整候选已在当前电脑应用并启动，22 项受管资源及原始备份哈希相符，离线引擎和公共词表与候选一致；启动后辅助功能结构显示紧凑“译文”按钮。用户随后进入工作时间并禁止桌面输入，拖动、展开、按钮点击和本轮完整回滚尚未验收；Mac 完整补丁仍未开放。

### macOS 自动检查的范围

macOS Intel 与 ARM64 分别记录实际系统、Node/Python 版本及架构，运行维护测试、8 项 Python 规则、文档、公共构建结构与标准 VSIX 打包。记录保存在各架构 Actions 产物中的 `ci-test-environment.json`，失败时也尽量保留，不能根据 runner 标签推断实际运行架构。

首次实际运行 [CI 40188066452](https://github.com/Txk1001/cursor-zh-offline/actions/runs/40188066452) 的两种 Mac 架构均在安装锁用例失败，原因是此前没有实现 Darwin 进程启动身份检查。现增加 BSD ps 分支，固定 C 语言和 UTC、校验完整输出；无法读取时安全拒绝，秒级精度下无法区分的同 PID 保守视为活动进程。新增模拟契约用例，并继续在真实 Mac runner 运行现有并发、进程中断与恢复测试，不跳过这些失败用例。修复后的最终结果以对应提交检查为准，完整安装的平台限制保持原样。

当前没有在 Mac 下载或启动 Cursor、改写应用、运行离线模型或核对界面。Windows 专用安装入口测试会明确跳过，通用安装事务和恢复测试仍执行。macOS 本轮也不执行 PowerShell 源码 ZIP 归档步骤；该步骤继续由 Windows、Ubuntu 检查。两套 Mac 产物分别命名，避免覆盖。自动检查成功仍不等于 Mac 完整汉化已支持。

使用公开人工样例，不上传私人聊天。对中文/英文混排、长段落、流式变化、节点复用、暂停/重连、查看原文/返回中文逐项核对。代码、命令、变量、路径、链接及快捷键应保持原样。记录真实窗口耗时；模拟长会话的无关变动不扫描大祖先，只证明对应测试条件。
