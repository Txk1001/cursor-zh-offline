# 简体中文术语与校对约定

| 英文 | 中文 | 使用说明 |
| --- | --- | --- |
| Agent | 智能体 | 产品交互与设置统一使用 |
| Subagent | 子智能体 | 保留命令 `/create-subagent` |
| Chat / Conversation | 对话 | 历史、列表与操作使用同一译名 |
| Repository | 仓库 | 项目与仓库按原义区分 |
| No Repo | 无仓库 | 空仓库状态，界面与离线精校词典统一 |
| Workspace | 工作区 | 不翻译实际目录名 |
| Fork chat | 从此处分支对话 | 保留原对话 |
| Prompt | 提示词 | 输入框内的用户内容不由界面补丁改写 |
| Follow-up | 后续消息 | 动词提示采用“发送后续消息” |
| Worked for | 耗时 | 动态数字保留，时间单位中文化 |
| Thought / Thought for | 思考用时 | 保留模型与专业术语名称 |
| Skipped | 已跳过 | 表示该提问或操作已跳过 |
| Pin / Unpin | 置顶 / 取消置顶 | 对话列表 |
| Archive | 归档 | 不与删除混用 |
| Undo / Redo | 撤销 / 重做 | 快捷键原样保留 |
| Select All | 全选 | 菜单与右键菜单统一 |
| Run | 运行 | 仅翻译已确认的运行按钮；保留快捷键、命令与 RPC 字段 |
| Always Run | 始终允许运行 | 表示后续运行授权，不能误写成持续重复运行 |
| Public preview | 公开预览 | 发布阶段，不是产品或协议名称 |
| Copilot / GitHub Copilot | 保留原名 | 产品名，不译为“副驾驶” |
| Playwright / Context7 | 保留原名 | 工具或产品名，不译为“游戏作家”“上下文7” |
| MCP Registry / GitHub MCP Registry | 保留原名 | 此处为技术服务名称；概念性解释可写“MCP 注册表”，不用“书记处” |
| Chrome DevTools / PyPI / npm / Docker Hub | 保留原名 | 开发工具及分发平台；原始链接同样保留 |
| Select Display Language | 选择显示语言 | 维护扩展命令与设置统一 |
| Open Language Pack Settings | 打开语言包设置 | 通过标准清单本地化资源显示 |
| Today / Yesterday | 今天 / 昨天 | 历史列表日期分组 |
| Minimap | 代码缩略图 | 编辑器界面 |
| Context | 上下文 | 百分比与上下文长度保留 |
| Cache | 缓存 | 与本地存储、会话记录区分 |
| Rollback / Restore | 回滚 / 还原 | 安装维护文档 |

## 校对规则

- 优先保留 Cursor 本身与标准语言包已有的准确中文，再复用社区资源补齐漏项；根据具体语境修订，不全局覆盖已有中文。
- 按钮使用简短动词，状态使用“正在…”或“已…”，避免生硬直译。
- 保留变量、占位符、快捷键、命令、路径、链接、模型名和代码。
- 数字和时间单位通过模板处理，避免将逻辑枚举替换为中文。
- 历史消息优先采用明确导入的人工词典；自动模型默认跳过已有中文的正文和标题，包括夹杂技术英文的中文段落。英文段落中的产品名按公共 `offline/protected-terms.json` 保留，不把所有通用概念都当作不可翻译术语。
- 自动模型仅补充可安全处理的英文内容，并标注“未校对”；原始消息保留，可切换查看。已有中文的正常保护不计为翻译失败。无法保留强调结构时保留原文并提示，不把整段塞入首个粗体节点。
- 新版本必须重新核对菜单、设置、输入框、历史页和编辑器，不以静态词典命中率代替界面检查。
- 尚未确认的译名标注“待确认”，取得实际语境后再合入。
