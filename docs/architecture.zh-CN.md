# 架构说明

本工程复用社区语言包构建与公开词典，以独立身份提供标准界面、硬编码界面和历史中文显示。范围见 [项目首页](../README.md)。

## 标准界面语言包

`microsoft/vscode-loc` 的固定 commit 提供编辑器中文基线；`src/i18n/zh-cn/` 合并 Cursor 词条。构建拥有 `vscode` 翻译标识；同一标识只选一个语言包文件，因此不能依靠同时安装两个语言包逐词合并。安装器处理已知语言包冲突。

`scripts/build.mjs` 产出扩展目录，`scripts/package.mjs` 产出 VSIX。默认 public 配置不读取本机元数据；显式 --profile=local 才按实际键过滤并核对占位符，不能将其产物作为公共发行。扩展运行代码负责必要的语言设置、冲突提示和离线服务维护。

## 硬编码界面

`scripts/translate-install.mjs` 在支持的 Windows x64 Cursor 安装上识别资源、核对版本与哈希、备份并应用补丁。字典来自 `hardcoded.json`、本地公共覆盖表和动态状态规则。启动文件与普通界面资源分别处理；已知资源锚点变化需要重新适配。

资源原件和恢复记录只留在用户状态目录。更新和恢复均受安装路径、commit 与哈希约束，未知版本不能强制沿用旧补丁。故障恢复需要测试写入失败和中断状态，具体事务实现以源码和测试为准。

## 历史显示层

`scripts/lib/history-localization.mjs` 为已加载的会话文字提供中文显示和原文切换。它维护原文与节点归属，监听增量变化并避开代码块、编辑器、输入框等区域；不修改聊天数据库。正文翻译可来自手动词典或本机引擎，自动译文显示未校对提示。

`scripts/lib/offline-client.mjs` 负责本机连接、批量请求、长文本处理与失败恢复。性能验收应检查无关节点变化、长会话和持续输出；仅检查调用次数不足以证明没有大范围文本读取。

## 离线引擎

Windows 嵌入式 Python 运行时载入 Argos en→zh 模型、SentencePiece 与 CTranslate2。资产版本、官方来源、哈希见 `offline/assets.json`；许可见 [离线依赖说明](../offline/THIRD-PARTY.md)。

`offline/engine.py` 处理公共精校短句、术语和技术标记保护，再运行模型。原文与译文缓存属于私人数据；模型结果不能替代人工校对。服务使用回环地址、访问令牌和来源限制；这些是应用层保护，不是独立操作系统沙箱。

## 分发

源码仓库不含 Cursor 原始程序、用户数据、运行时资产或本机提取元数据，公共来源记录除外。源码 ZIP 可独立构建；完整离线 ZIP 添加已验证的 VSIX、模型与依赖。所有内容经文件清单校验。参阅 [发布流程](publishing.zh-CN.md)。
