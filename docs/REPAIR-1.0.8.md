- Agents 的编辑菜单已检查“撤销、重做、剪切、复制、粘贴、全选”；传统编辑器首页、菜单和工作台已显示中文。

- 核对期间 Cursor 自动升级到 3.27.12；旧 commit 的回滚被正确拒绝，旧备份保留，随后按新 commit 单独适配。

## 自动检查

`npm test` 统一执行配置读写、历史规则、安装/恢复失败路径、动态 DOM 与性能、启动生命周期、版本入口及仓库检查。`npm run verify` 检查资源结构与标准键覆盖。离线接口检查支持独立 `--state` 目录，已实际安装并检查锁定的 Windows 运行时。

标准资源覆盖：简体核心工作台 12841/12841，其中 Cursor 新增项 1864/1864。测试资源键不计入界面覆盖。VSIX 包含 95 个 NLS 资源包。该比例不代表所有动态界面、第三方页面或历史正文已经人工精校。

示例修正：`The operation completed in 15 seconds.` 现在显示为“操作已完成，用时 15 秒。”；不同数字与代码片段也有回归用例。

## 分发与复核

完整包包含当前版本 VSIX、17 项锁定运行资产、维护源码、tests、GitHub 工作流、术语与许可。每个文件的校验值记录在 `MANIFEST.sha256`，ZIP 校验值另存为同名 `.sha256` 文件。安装包不含个人历史词典、聊天数据库、连接令牌、缓存、程序备份或本机提取元数据。

安装后可按 [主说明](../README.md) 更新和回滚；维护者按 [验证清单](VALIDATION.md) 继续记录新环境与版本。

## 仍需保留的限制

1. 本轮实际环境为 Windows x64；3.27.6 和 3.27.12 分别有本轮核对记录。全新 Windows 账户、其他硬件、macOS/Linux 与其他 Cursor 版本未全面验收。
2. GitHub Actions 已补齐，但尚未在独立公开仓库远端执行；本地预览包不冒充市场正式发布版。
3. 任意历史消息的机器翻译仍可能有错；公共精校词典、个人覆盖和原文查看用于持续改善质量，不能承诺全部自动译文达到人工精校水平。
4. 补充了本次检查指出的两项组件许可材料，不将此表述为全部原生依赖的法律合规认证。
