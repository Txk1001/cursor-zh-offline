## 执行方式

首次安装双击完整包的安装离线汉化.cmd。自定义目录示例：

```powershell
node scripts/portable-install.mjs --dir="D:\Apps\Cursor" --with-offline
node scripts/translate-install.mjs --undo --dir="D:\Apps\Cursor"
```

测试文本使用人工构造的普通说明、`const message = "Hello";`、`{{account}}`、`$HOME`、`npm install`、`Ctrl+Shift+P` 和 `https://example.com/docs`；不要导入私人会话用于公开测试。关闭软件前保存工作；不要为了测试破坏真实安装文件，在隔离测试目录中注入故障。

独立环境暂不可用时，写明待验收，不填写通过、不扩大平台支持、不公开为已可靠验收的版本。
