# cursor-zh-offline

An independent, local-first Simplified Chinese integration for Cursor. Version 1.1.0 is a preview. Source: [Txk1001/cursor-zh-offline](https://github.com/Txk1001/cursor-zh-offline). Offline installation archives are currently delivered locally; no GitHub Release or extension marketplace publication is claimed.

The complete patch admits Windows x64 with Cursor 3.27.6 or 3.27.12. Other versions and operating systems require adaptation and acceptance. Translated history is a display layer: originals remain available, and machine-generated output is marked as unreviewed.

See the current [scope and installation](../README.md), [contribution guide](../CONTRIBUTING.md), [release workflow](publishing.md), [privacy guidance](../SECURITY.md) and [acceptance checklist](VALIDATION.md). Passing local tests does not imply a successful remote CI run, a clean-user installation, or complete UI coverage.
