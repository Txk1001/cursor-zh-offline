# Cursor 汉化配置任务提示词

将下列内容复制给执行配置任务的 Agent。仓库位置、候选版本和操作范围优先沿用用户当前指令与仍有效的既有授权；未提供的信息先通过只读检查确定，不将本模板本身视为安装、关闭应用或修改系统的额外授权。

## 可复制提示词

请协助配置当前仓库的 Cursor 简体中文集成。先阅读仓库上层适用规则、[项目 AGENTS.md](../AGENTS.md)、[手动与 Agent 配置说明](../docs/AGENT-SETUP.zh-CN.md)、[验收状态](../docs/VALIDATION.md) 和 [测试环境说明](../docs/TEST-ENVIRONMENTS.zh-CN.md)。以当前配置和对应版本实际证据为准，不以目录名称、旧截图或旧交接说明代替核验。

### 1. 先只读核对并报告

1. 探测操作系统及构建版本、CPU 架构、当前用户权限、Cursor 运行状态和所有安装位置。读取真实 Cursor 的完整版本、commit 与 Code OSS 版本，确认唯一目标；存在多个安装时不自行挑选并改写。
2. 记录这是当前用户、同机新用户、干净虚拟机还是备用机；检查系统 Node/Python、已有语言包、用户配置、翻译状态和配对记录是否存在。仅检查存在性或必要元数据，不读取私人词典、令牌、`connection.json` 内容、聊天数据库、聊天正文或缓存原文。
3. 核对候选提交、包名、来源、SHA-256、包内清单和版本一致性，检查 VSIX 的 `engines.vscode` 是否兼容目标 Cursor 的 Code OSS。使用官方来源和用户指定的项目候选入口；没有可核验的哈希、包不完整或校验不符时不安装。
4. 区分标准 VSIX、硬编码界面/历史显示补丁、Windows x64 完整离线运行时。检查当前安装器实际支持的系统和版本；不能只改白名单、删平台拒绝或关闭系统保护来通过检查。
5. 先用一条清楚的进度消息输出“目标环境、候选与校验结果、适用范围、具体步骤、尚缺证据”。随后在用户本轮及此前仍有效的授权范围内继续，不因已经授权的常规步骤反复索要许可。

如果用户只要求方案、文档或只读检查，到此提供结果，不改程序、启用系统功能或退出应用。如果安装已获授权，继续执行以下对应平台流程。只有出现实质性歧义或超出已授权范围的操作时，才明确说明缺少什么；同时完成不受影响的检查工作。

### 2. Windows 完整补丁流程

仅在系统、架构和 Cursor 版本符合当前准入规则时执行。默认历史控制条为紧凑模式、右上角，先在对应候选包或源码根目录预览：

```powershell
node scripts/translate-install.mjs --preview --history-controls=compact --history-position=top-right
```

多个安装或非默认位置须先确定明确目标，并在预览、应用和恢复命令中使用同一个 `--dir="安装目录"`。命令需要可用的 Node.js 22 或已核验的 Cursor 内置运行时；普通用户无系统 Node/Python 验收时，不临时安装系统开发工具来掩盖依赖问题。

检查预览的目标、版本、预计改写资源和恢复信息；遇到未知资源修改、冲突、损坏安装记录或版本不匹配时停止应用并诊断，不强制覆盖。真实安装已获授权时，保存用户工作、完全退出指定 Cursor、确认进程停止，核对原始资源备份和恢复入口，然后使用相同参数去掉 `--preview`：

```powershell
node scripts/translate-install.mjs --history-controls=compact --history-position=top-right
```

只有离线运行时也在本次任务范围内时，附加 `--with-offline`：

```powershell
node scripts/translate-install.mjs --history-controls=compact --history-position=top-right --with-offline
```

首次资产准备需要网络，下载与校验完成后另做断网运行检查。不得将准备资产时联网描述为已完成离线验收，也不得把标准 VSIX 当作完整离线包。

历史控制条参数只允许 `--history-controls=compact|expanded` 以及 `--history-position=top-right|top-left|bottom-right|bottom-left`，实际命令每个参数只填一个值。未指定时默认 `compact` / `top-right`。与本次安装预设 `defaultsKey` 匹配的本机已保存布局优先；因此重新安装相同预设不一定覆盖原先的展开状态或拖动位置。窗口内“译文”按钮用于展开，“恢复预设位置”恢复本次预设的位置与展开状态并清除拖动坐标；偏好仅保存在本机对应界面的存储中。这些默认值本身不会更改系统设置，预览也不代表已经应用。

在已授权范围内重新打开 Cursor，检查真实界面、原文完整性、技术片段保护、离线连接、重复安装及同版本回滚；按 [Windows 实机验收表](../docs/WINDOWS-ACCEPTANCE.md) 记录结果。故障注入仅在隔离副本进行，不破坏真实安装。没有执行的步骤和没有打开的页面状态必须保留待验收。

### 3. macOS 流程

Mac 当前只进行标准 VSIX 语言层基线评估，仍待实际设备验收。记录 Apple 芯片或 Intel、ARM64 或 x64、系统和 Cursor 完整版本；核对 VSIX 哈希与引擎兼容性后，才在已授权的专用测试用户中安装标准 VSIX、选择简体中文并检查真实显示。安装和重启同样遵守已有授权范围，先保留已有语言包配置及恢复方式。

不执行 Windows 完整补丁或 Windows 离线运行时，不删除平台拒绝，不关闭 Gatekeeper，不承诺历史控制条、硬编码界面和离线正文翻译在 Mac 已经可用。Mac 结果不能补齐 Windows x64 的独立环境验收；不同架构也分别记录。

### 4. 全程限制与交付

- 不批量删除文件、目录、缓存、备份或旧产物，不通过循环、通配符或清理脚本绕过限制。需要批量删除时停止该部分并请用户手动处理。
- 不读取或输出私人翻译词典、令牌、连接文件内容及私人聊天；测试使用人工构造的公开样例。脱敏截图，不把个人状态和本机报告提交到公共仓库。
- 不擅自启用 Sandbox、修改系统安全设置、重启电脑、结束无关程序、推送 Git、创建标签或发布产物。只执行用户明确要求及仍有效授权覆盖的操作。
- 最终用中文简要报告：实际目标与候选、校验结果、已执行的配置、真实验证结果、原件与恢复方式、失败项和待验收范围。文件存在、命令成功、预览通过或自动测试通过都不能写成完整实机验收通过。
